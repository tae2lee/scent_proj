# scent_proj

remember the scent

걸그룹 리센느(RESCENE)의 앨범, 일정, 멤버, 앨범별 향을 모아 둔 비공식 팬 아카이브입니다. `index.html` 한 파일로 되어 있어요.

## 구성

- **앨범**: 발매작 카드와 수록곡. 곡 이름을 누르면 YouTube Music으로 연결되고, 곡을 고른 뒤 멤버를 누르면 무대·직캠·풀캠·얼빡캠·페이스캠을 한 번에 검색합니다.
- **일정**: 발매, 방송, 행사, 대학 축제, 시상식. 일정마다 팬들이 직캠 제목에 쓰는 키워드(날짜 6자리 + 장소 + 리센느)로 비공식 직캠을 검색할 수 있습니다.
- **멤버**: 멤버별 직캠, Focus cam, 외부 콘텐츠 검색.
- **향**: 앨범마다 공식 향(플로럴, 앰버그리스, 비누, 비 온 뒤 풀향, 베리, 인센스, 머스크)과 어울리는 향수 후보, 팬 투표.
- 언어: 한국어, English, 中文, 日本語

## 실행

`index.html`을 브라우저로 열면 됩니다. GitHub Pages로 배포하려면 저장소 Settings → Pages에서 `main` 브랜치 루트를 선택하세요.

투표, 팬 추천, 앨범 커버 업로드는 claude.ai 아티팩트의 저장 기능(`claude.use("db")`, `claude.use("assets")`)을 씁니다. 다른 곳에 배포하면 이 기능들은 꺼지고 나머지는 그대로 동작합니다. 직접 배포에서 투표를 살리려면 Supabase나 Firebase 같은 저장소를 붙여야 합니다.

## 데이터 출처

발매·일정 정보는 언론 보도와 팬 일정 사이트를 바탕으로 정리했고, 향수 노트는 각 브랜드가 공개한 정보를 따랐습니다. 영상과 음원의 권리는 각 권리자에게 있으며, 페이지의 링크는 YouTube 검색으로 연결됩니다.
